Access proxy (forward-auth)

Lets a reverse proxy (Traefik, nginx, Caddy) ask SpireUEM whether the device behind a request is COMPLIANT. The connector is a service account holding posture:read. Everything here is fleet-wide and defaults to deny.

{{if .Saved}}
Settings saved and audited.
{{end}}

Forwarded client addresses and certificates are only believed from these sources. Empty = forward-auth denies every request.

An IP address can be spoofed or shared on a LAN. Enable it only where the address is bound to a device, for example a WireGuard or NetBird overlay. Several devices on one address are denied.
