Access Posture

One fleet-wide rule set decides each device's access verdict (COMPLIANT, NONCOMPLIANT, QUARANTINED or UNKNOWN). Connectors (reverse-proxy forward-auth, Authentik, RADIUS) read that verdict; they never decide for themselves. Rule set version {{.Rules.Version}}. Every edit is versioned and audited.
