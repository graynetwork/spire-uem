Device CA

The certificate authority that signs every device certificate (agent, network and browser). Install this certificate as the trust anchor on the RADIUS server (EAP-TLS) and on a TLS-terminating reverse proxy that asks browsers for a client certificate. It is public: it only verifies leaf certificates.
