Desktop Background Asset Upload (Optional)

Upload image to distribute to /usr/share/backgrounds/.

Renders a dedicated table inet spire only. Outbound traffic is always left open so the agent keeps its control-plane link.

Ports and CIDRs are validated server-side before the policy is saved.

Uses Debian drop-in config (pwquality.conf.d, faillock.conf, login.defs, sudoers.d/90-spire). Leave a field blank to leave it unmanaged.

Each PEM is validated as a CA certificate server-side, installed to /usr/local/share/ca-certificates/spire/, and converged with update-ca-certificates.

For multiple CAs, use the Raw JSON Payload Override below with {"certificates":[{"name":"...","pem":"..."}]}.

Autoconnect

Secrets (Wi-Fi PSK, 802.1X password) are sealed with the server KEK at save and never shown again. The agent writes keyfiles to /etc/NetworkManager/system-connections/spire-<id>.nmconnection (0600, root).

The device generates its own WireGuard private key locally and reports the derived public key back in its compliance output — register that as the device's peer upstream. The server never holds the private key.

Warning: with HID allow disabled, a device with no other allow-list match can lock out its keyboard and mouse. Only disable this if you understand the lockout risk.

On first apply in block-new mode, devices currently plugged in are grandfathered so nothing already connected breaks.

Agent writes /etc/audit/rules.d/90-spire.rules, validates with augenrules --check, loads with augenrules --load; other rules files are never touched.
